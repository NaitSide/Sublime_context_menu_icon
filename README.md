# Sublime Text — Context menu icon

🛠️ PowerShell GUI-утилита для добавления Sublime Text в контекстное меню Windows.

Работает для файлов, папок и фона папки — правый клик по пустому месту внутри папки.

![Sublime Text Context Menu Icon](screenshot.png)

---

## ✨ Возможности

- Добавляет пункт **"Открыть в Sublime Text"** в контекстное меню Windows
- Добавляет иконку Sublime Text рядом с пунктом меню
- Работает для файлов, папок и фона папки
- Запускается как GUI-приложение
- Автоматически запрашивает права администратора через UAC
- Не требует `.bat`-файла
- Удаляет старые записи перед добавлением новых
- Отключает восстановление старой сессии Sublime
- Исправляет глюк с повторным открытием старой папки сбоку
- Делает бэкап настроек Sublime перед изменением
- Позволяет выполнить полный откат изменений

---

## 🧠 Что исправляет по сравнению со старой версией из папки legacy_v1

В стандартном поведении Sublime Text может запоминать старую сессию.

Например:

1. Открываешь папку через контекстное меню
2. Закрываешь Sublime Text
3. Открываешь отдельный файл
4. Sublime открывает файл, но сбоку снова показывает старую папку

Скрипт отключает восстановление старой сессии, чтобы Sublime открывал именно то, что выбрал пользователь:

- 📄 файл открывается как файл
- 📁 папка открывается как папка
- 🚫 старая папка не подтягивается при открытии нового файла через ПКМ
- ✅ поведение становится чистым и предсказуемым
